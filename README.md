# Nuri

여러 AI 에이전트가 하나의 브라우저에서 동시에, 각자 자기 탭에서 일하게 해 주는 데스크톱 앱입니다.

## 다운로드

👉 **[최신 버전 받기](../../releases/latest)**

| 내 컴퓨터 | 받을 파일 |
|---|---|
| Mac (M1·M2·M3·M4 등 Apple Silicon) | `Nuri-…-mac-arm64.dmg` |
| Mac (Intel) | `Nuri-…-mac-x64.dmg` |
| Windows | `Nuri-…-win-x64.exe` |
| Linux | `Nuri-…-linux-x86_64.AppImage` |

설치 방법과 처음 실행할 때 뜨는 경고를 넘기는 법은 각 릴리스 페이지에 있습니다.
한 번 설치하면 이후 업데이트는 앱이 알아서 받습니다.

이 레포에는 설치 파일만 올라옵니다.
